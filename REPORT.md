## 2. Контрольне запитання

**Запитання:** `Що таке рекурсія? Наведіть приклад рекурсивної функції.`

**Відповідь:**

`Рекурсія - це спосіб програмування де программа викликає сама себе для отримання якогось результату.`

`Приклад рекурсивної функції`
```python
def recursive_sum(a: int):
    if a > 0:
        return a + recursive_sum(a - 1)
        
    return 0

def main():
    result = recursive_sum(5)
    print(result)
    # Виведе: 15
```

`У цій программі рекурсивна функція викликається для того щоб підрахувати суму чисел де кожне наступне зменшується на один.`
